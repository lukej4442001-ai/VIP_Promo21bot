# VIP_Promo21bot
Advanced Telegram promo & bonus bot with spin, streak, VIP tiers, tasks, promo codes & withdrawals.

## Railway Deploy
1. Push to GitHub
2. Railway → New Project → Deploy from GitHub
3. Add Variables:
   - BOT_TOKEN = xxx
   - ADMIN_ID = your_telegram_id
   - FORCE_JOIN_CHANNEL = @yourchannel (optional)
   - FORCE_JOIN_LINK = https://t.me/yourchannel (optional)
4. Deploy. Done.
